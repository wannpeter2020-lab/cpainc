Cvent RFP Download

Before working with an RFP in CPAinc, you will need to download it from Cvent. There are two documents you may need: the RFP Word document (the event requirements) and the CRF Excel file (hotel proposals for import).

Part 1 — Download the RFP (Word Document)

1
Log into Cvent and locate the RFP

Go to suppliers.app.cvent.com. On the All RFPs and Bookings screen, find your event in the list and click on it.

2
Click Request Details → Download RFP → Word document

In the left sidebar, click Request Details. Then click the Download RFP button in the top-right and select Word document from the dropdown.

3
File downloads to your Downloads folder

The RFP Word document will appear in your browser's download bar and save to your Downloads folder. You can now use it or attach it when creating an RFP in CPAinc.

Part 2 — Download the CRF (Excel)

The CRF (Compete for Revenue Form) is the hotel proposals spreadsheet. Use this when you want to import hotel bids into CPAinc via Import CRF on the RFP Detail page.

1
Click Venues, then select hotels

In the left sidebar, click Venues. The Venue Response list appears. Check the hotels you want included in the CRF — you can select a short list, a single hotel, or all available venues using Select all.

2
Click Reports → CRF (Excel)

With your hotels selected, click the Reports button in the toolbar at the top of the venue list. In the dropdown, select CRF (Excel).

3
CRF downloads to your Downloads folder

The Excel CRF file will appear in your browser's download bar and save to your Downloads folder. You can now use Import CRF on the CPAinc RFP Detail page to bring the hotel data in automatically.

Once you have the CRF Excel file, go to the RFP Detail page in CPAinc and click Import CRF to automatically populate all hotel details from the spreadsheet.

Upload Contract & Extract Data

CPAinc can read a hotel contract (PDF or Word) and automatically pull out the key terms — room block, rate, cutoff, attrition, and contacts — so you don't have to type them in manually.

Contract data is extracted by Claude AI. The review page lets you correct anything before saving, so it's always safe to upload even if a field comes back wrong.

Step by Step

1
Open the event in Pickup Tracking & Reporting

Click the event name or Pickup History button from the dashboard to open the Event Detail page.

2
Click "Upload Contract"

The button is in the top-right area of the event page. A file picker will open.

3
Select your contract file and click "Extract Contract Data"

Accepts PDF or Word (.docx) files. The app sends the contract text to Claude, which extracts:

  • Night-by-night room block (date → number of rooms)
  • Nightly contracted rate
  • Cut-off date
  • Attrition %
  • Hotel contact name and email
  • Client contact name and email
4
Review and correct on the Review page

All extracted fields are shown before anything is saved. The room block table is editable night-by-night — if Claude misreads a single night you can correct it right here inline before committing.

Booking data is downloaded from my.conferencedirect.com and then imported into CPAinc.

Part 1 — Download the Associate Booking Report

1
Log in and open the Report Browser

Go to my.conferencedirect.com. Click Reports in the navigation, then select Associate Booking Report from the report list.

2
Set the date range and download

Click Booked Date to open the date filter. Select Specific Dates, enter your From and To dates, then click Apply. The report will download to your Downloads folder automatically.

3

4

Importing an HHR (Housing History Report) — Step by Step

The Housing History Report is the official final room pickup file sent by the hotel after the event's cutoff date. Import it to record the actual rooms used for the event.

1
Receive the HHR file from the hotel

The hotel sends this as an Excel (.xlsx) file, typically within a few days after the cutoff date. Save it to your Downloads folder.

2
Go to Import → HHR

Click Import in the navigation bar and select HHR.

3
Select the event and upload the file

Choose the matching event from the dropdown, then select your HHR file. Click Import.

4
Review the summary

The system shows the total rooms imported by night. The event's final pickup is now recorded and the booking moves toward commission tracking.

After importing the HHR, use Enter Final History on the Pickup Event Detail page to confirm the final pickup numbers and mark the event complete.

Use this import to bulk-update booking statuses to Cancelled from a spreadsheet — useful after receiving a cancellation report from ConferenceDirect.

Prepare your file

2
Go to Import → Cancelled Meetings

Click Import in the navigation bar and select Cancelled Meetings.

3
Select your file and click Import

The system updates each matching booking's status to Cancelled and shows a summary of how many records were updated.

Only Booking IDs already in CPAinc will be updated. IDs not found in the system are skipped and listed in the import summary.

Setting Account Access

Account Access controls which client organisations a non-admin user can see across Bookings, Pickup Tracking and Reporting, RFPs, and the Status Board.

1
Click the 🏢 buildings button

In the Account Access column for the user you want to configure.

2
Check the accounts this user should see

Use the search box to find specific clients. Use Select All / Clear All for bulk changes.

3
Click "Save Access"

The user immediately sees only their assigned accounts on next page load.

If a user has no accounts assigned, they will see no records anywhere in the app. Admins always see everything.

Resetting a Password

1
Scroll to "Reset Password"

At the bottom of the User Management page.

2
Select the user and enter a new password

Minimum 6 characters.

3
Click Reset

The user can now log in with the new password.
