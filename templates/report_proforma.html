How Projections Work

For every unpaid Definite event with a meeting end date in 2026 or later:

  1. Look up the brand's 6-month average days from meeting end to commission received (rolling window ending today)
  2. If no brand match → use the chain's 6-month average
  3. If no chain match → use 90 days
  4. Projected payment date = Meeting End Date + avg days
  5. Estimated commission = Commissionable Amount × Commission %

If the projected date falls in a later year, the event automatically rolls to that year's tab.
